# Cloudloom Nectar — Windows and Mac

## Что нового

- **Delivery теперь подключается к Проводнику Windows.** Используется сохранённый вход через пользовательский API; отдельный WebDAV-адрес не нужен. Чтение по частям, загрузка файлов, папки, переименование и удаление работают с правами вашего аккаунта. Маленькая кнопка диска рядом с профилем открывает его настройки.
- **30 сервисов с инструкциями для входа.** Добавлены put.io, Zoho WorkDrive и 1Fichier, включая отдельные значки. Для Zoho регион указывается до входа, для 1Fichier API-ключ скрыт как пароль.
- **Новое имя Nectar** в окне, интерфейсе и пакетах. Проверочная Maple с поддержкой Delivery заменяется полноценным релизом.
- **Автообновление при запуске.** Cloudloom получает новый подписанный пакет из официального GitHub-релиза, проверяет подпись и версию, устанавливает обновление и открывается заново. Maple, включая локальную проверочную сборку, может обновиться до Nectar без ручного скачивания. Перед перезапуском завершите передачи и отключите диски в Cloudloom. [Как работают обновления](https://github.com/prostoodin1/cloudloom-desktop/blob/cloudloom-nectar/docs/UPDATES.md).

## Диски в Проводнике

Все сервисы каталога доступны для подключения диском Windows. Возможности операций зависят от провайдера, тарифа и прав аккаунта. Выберите свободную букву D–Z, локальное название и значок. По умолчанию включено **только чтение**; для загрузки и изменения файлов снимите этот флажок перед подключением. Диск доступен, пока открыт Cloudloom; автоподключение при следующем запуске включается отдельно.

Нужен WinFsp. Официальный установщик включён в Windows-пакет; Cloudloom проверяет его SHA256 и предлагает запуск только после подтверждения. Windows может запросить права администратора. Сам Cloudloom запускайте обычным пользователем, как Проводник. На Mac подключение в Finder пока не реализовано.

Кэш хранится локально без дополнительного шифрования. Целевой максимум — 10 ГиБ, резерв — 1 ГиБ; открытые и неотправленные файлы могут превысить мягкий лимит. Запись Delivery также требует места для временного файла. Не удаляйте кэш с неотправленными изменениями. Перед отключением закройте использующие диск программы и дождитесь отправки. Перемещение Delivery поверх существующего элемента отклоняется с сохранением обоих файлов. [Подробности](https://github.com/prostoodin1/cloudloom-desktop/blob/cloudloom-nectar/docs/EXPLORER.md).

## Загрузки

- **Cloudloom_Nectar_Windows_x64_Setup.exe** — установщик Windows 10/11 x64, поддерживает автоматические обновления.
- **Cloudloom_Nectar_Windows_x64_Portable.zip** — распакуйте целиком, сохраняя resources рядом с cloudloom.exe. Требует WebView2. Последующее автообновление выполняется установщиком.
- **Cloudloom_Nectar_macOS_Intel.dmg** — Intel Mac, macOS 13+.
- **Cloudloom_Nectar_macOS_AppleSilicon.dmg** — Mac с M-чипом, macOS 13+.
- Также приложены Mac ZIP, три подписанных updater-пакета, подписи, SHA256 и latest.json. На Mac скопируйте приложение в Applications перед запуском.

## Проверки и ограничения

Проверены 14 frontend-тестов и 23 Windows Rust-теста, включая настоящий временный диск WinFsp, чтение Delivery без предварительного кэша, запись, переименование, папки и режим только чтения. Тесты используют изолированный SFTPGo-совместимый API, не рабочие файлы студии. Формы и инструкции всех 30 сервисов проверены в интерфейсе; вход в реальные аккаунты новых сервисов требует данных владельца и отдельно не проверялся. CI дополнительно собирает и проверяет Windows, Mac Intel и Mac Apple Silicon; публикация зависит от успеха всех платформ.

Видео и аудио читаются диапазонами байтов, если сервер поддерживает их. Нет атомарного согласования одновременных изменений между Проводником, Cloudloom и другими клиентами. Proton Drive использует beta-адаптер. Запросы и хранение могут тарифицироваться провайдером.

Подписи обновлений не заменяют сертификаты издателя: Windows не имеет Authenticode-подписи, Mac имеет ad-hoc подпись без Developer ID/notarization. SmartScreen/Gatekeeper могут показать предупреждение. Не отключайте защиту ОС.
