# Cloudloom Quartz

«Передачи» открываются отдельным экраном из главного меню и из профиля. Здесь видны передачи Cloudloom и отправки с дисков Проводника. Завершённые и неудачные записи можно убрать из истории. Значки состояния остаются в списке файлов Cloudloom.

Delivery отправляет файлы из Проводника без второй временной копии. Чтение идёт без дискового кэша. Буфер записи хранит незавершённые файлы для повторной попытки и освобождается после отправки.

При обрыве скачивания Delivery продолжает чтение по диапазонам, если сервер подтверждает, что файл не изменился. Иначе Cloudloom автоматически начинает новую попытку. Итоговый файл появляется после проверки размера. Продолжение после закрытия приложения пока недоступно.

Под главным меню виден объём успешных скачиваний через Cloudloom за текущий календарный месяц на этом компьютере.

## Загрузки

- **Cloudloom_Quartz_Windows_x64_Setup.exe** — Windows 10/11 x64 с автообновлением.
- **Cloudloom_Quartz_Windows_x64_Portable.zip** — распакуйте целиком. Нужен WebView2.
- **Cloudloom_Quartz_Windows_x64_ExplorerOverlay.zip** — необязательное расширение со значками прямо в Проводнике. Установка из отдельного ZIP требует прав администратора. Прочтите README.txt.
- **Cloudloom_Quartz_macOS_Intel.dmg** — Intel Mac, macOS 13+.
- **Cloudloom_Quartz_macOS_AppleSilicon.dmg** — Mac с M-чипом, macOS 13+.

На Mac скопируйте приложение в Applications. При переходе с предыдущей версии Cloudloom завершите передачи и отключите диски перед перезапуском.

Проверены скачивания с принудительным обрывом, повторная попытка при изменении файла, отправка через WinFsp и интерфейс передач. Полное скачивание 50 ГБ не замерялось. Windows может не отобразить значки расширения, если Проводник уже занял доступные места другими обработчиками.

Подписи автообновлений проверяют пакеты Cloudloom. Windows пока без Authenticode, macOS использует ad-hoc подпись. [Политика подписи](https://github.com/prostoodin1/cloudloom-desktop/blob/main/docs/CODE-SIGNING.md).
