# Живой интерфейс Cloudloom Harbor

Harbor проверяет опубликованный `live-ui/catalog.json` в ветке `live-ui` этого публичного репозитория при запуске, возвращении в окно и раз в минуту в активном окне. Исходный JSON редактируется в `main`; workflow **Publish live interface** проверяет его тестами и публикует в `live-ui` автоматически после успешной проверки. Кнопка «Проверить интерфейс» выполняет проверку вручную. React обновляет данные на месте: окно не перезагружается, профили, передачи и несохранённый текст остаются на месте. Glimmer и более старые версии нужно один раз заменить на Harbor.

Для публикации измените JSON в `main` и увеличьте целое `revision`. Сохраните commit/push (либо сохраните файл через GitHub). GitHub Actions запустит тесты и опубликует каталог в `live-ui`; сборка установщиков не нужна. Версии ниже или равные уже принятой игнорируются; workflow также запрещает публикацию изменённого каталога без увеличения revision. Для отката содержимого опубликуйте прежние значения с новым, большим revision. Задержки GitHub/CDN и отсутствие сети могут отложить обновление; обещания мгновенной доставки нет. Не редактируйте опубликованную ветку напрямую.

Пример изменения без сборки приложения:

```json
{
  "schema": 1,
  "revision": 2,
  "ui": { "subtitle": "Подключите облако или Delivery." },
  "services": {
    "delivery": {
      "description": "Файлы Delivery через WebDAV",
      "guide": {
        "intro": "Используйте подтверждённый администратором WebDAV URL.",
        "steps": ["Получите адрес подключения у администратора Delivery.", "Введите адрес, логин и пароль приложения в Cloudloom."]
      }
    }
  }
}
```

Разрешены подписи стартового экрана, акцентные цвета, названия, описания и тексты инструкций уже встроенных сервисов. Неперечисленные значения берутся из встроенной версии. Неизвестные ID сервисов игнорируются для совместимости со старыми клиентами.

Это **не загрузка исполняемого кода** и не произвольная замена React-компонентов. Нельзя менять endpoint авторизации, адаптер, OAuth-настройки, поля ввода, ссылки помощи или права приложения. Добавление нового адаптера, новых действий, исправления файлового движка и произвольная новая разметка требуют новой сборки. JS, CSS и HTML из GitHub не исполняются. Тексты выводятся как текст React. JSON ограничен 128 KiB, запрос — 8 секундами. Ошибка или отсутствие сети оставляет рабочую встроенную/последнюю принятую версию; валидный каталог кэшируется локально. Запросы к raw.githubusercontent.com не передают токены хранилищ, cookies, имена профилей или файлов.

Для Delivery нужен включённый SFTPGo WebDAV и выданный администратором HTTPS endpoint. `https://delivery.studiored.es/web/` — только веб-вход. Cloudloom не включает протоколы и не создаёт учётные записи на сервере.
